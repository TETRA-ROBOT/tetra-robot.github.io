현장에 맞춘 6가지 모델

모델마다 센서와 구동 장치는 다르지만, 같은 ROS 2 패키지와 같은 관리 화면으로 운영합니다.

TETRA-M

표준 모델

전방 SICK 2D 라이다, 후방 초음파 또는 Cyglidar D2, USB 카메라와 AprilTag 위치 보정.

TETRA-H

고하중 모델

듀얼 라이다 병합, Realsense RGB-D 카메라, GPIO 기반 주변 장치 제어.

TETRA-EDU

교육·연구용

Kanavi 라이다 드라이버를 지원하는 연구·교육용 플랫폼.

TETRA-MH

리프트·토르소 모델

Herkulex 모터 기반 리프트·토르소와 오토닉스 RGB-D 센서 탑재.

TETRA-S

소형 모델

3D RTAB-Map SLAM과 자율주행을 지원하는 컴팩트한 차체.

TETRA-SM

라인 도킹 모델

레이저 라인 추출과 라인 도킹 감지로 정밀하게 충전기에 붙습니다.

Software

로봇 한 대의 두뇌부터 관제실까지

로봇마다 싱글관제(tetra_integration)가 돌고, 멀티관제(TetraFleetManagement)가 여러 로봇의 싱글관제에 연결해 일을 나누고 교통을 정리합니다.

tetra_integration · 싱글관제

6종 모델의 ROS 2 패키지(드라이버·Nav2/SLAM·자동 도킹·Gazebo 시뮬레이션)와 로봇별 웹 관리 화면을 하나로 묶은 통합 저장소입니다. 지도 만들기, 장소 저장, 태스크·반복 작업, 수동 조종, 가상벽·속도 구역, 진단까지 로봇 한 대에서 필요한 모든 것을 다룹니다.

TetraFleetManagement · 멀티관제

여러 대의 로봇에 미션을 나눠 주고(가장 빨리 닿을 로봇 배정), 좁은 통로·교차로 교통을 정리하고, 배터리가 낮으면 충전소로 보냅니다. 로봇을 모르는 사람도 알아볼 수 있는 쉬운 상태 문장과 알림별 해결 순서를 보여 줍니다.

멀티관제 주요 기능내용
미션·배정이동·배송·순찰·충전 미션을 우선순위 순으로 가장 빨리 닿을 로봇에 배정하고, 도착 예정 시각을 보여 줍니다.
교통 관리좁은 통로·교차로·진입 금지 구역, 길목 시간 예약, 교착 자동 해소.
자동 충전기준 배터리 아래로 내려가면 가까운 빈 충전소로, 꽉 차면 대기 장소에서 기다립니다.
공용 지도회사·지도가 다른 로봇도 지도 맞춤으로 같은 장소·교통 구역을 씁니다. 2D·3D 보기.
시뮬레이터실제 지도 위에 가상 로봇 1~20대를 띄워 배속을 바꿔 가며 운영을 미리 시험하고 결과 보고서를 받습니다.
연동VDA 5050 3.0, 문·엘리베이터, WMS·MES 웹훅과 연동 토큰.
